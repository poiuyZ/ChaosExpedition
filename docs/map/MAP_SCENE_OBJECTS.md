# Chaos Expedition 场景元素清单

> 状态：规划清单，未创建或摆放任何场景对象。文中的元素 ID 是文档内的方案标识，不是 Warcraft III rawcode。

## 1. 已验证的资源与对象信息

### 地形调色板

只读解析 `maps/map/war3map.w3e` 得到基础 tileset `L`、自定义 tileset 标志 `0`，以及以下现存调色板 ID：

| 类别 | 已存在 ID |
|---|---|
| 地面调色板 | `Ldrt`, `Ldro`, `Ldrg`, `Lrok`, `Lgrs`, `Lgrd` |
| 悬崖调色板 | `CLdi`, `CLgr` |

这些 ID 已出现在当前地形文件调色板中；本清单不猜测其视觉名称、适用地貌或 1.27b 渲染效果。编辑器里应先核对，再决定各区域的地面和悬崖组合。

`maps/resource/` 有 104 个文件，包含多套导入地形贴图及 UI/模型相关文件。`maps/table/imp.ini` 中的导入登记不等于贴图已在当前 tileset 中启用；当前 W3E 标记为非自定义 tileset。

### 已验证的起点对象

`war3mapUnits.doo` 使用已有只读解析器解析成功：格式 `W3do`、版本 8、子版本 11，共 4 个单位；四者 rawcode 均为 `sloc`，坐标见 [MAP_SCENE_COORDINATES.md](./MAP_SCENE_COORDINATES.md)。起点朝向数值被解析为 `4.712389...`，单位语义仍标记为 unknown，因此不将其换算或作为新摆放朝向。

### 尚未验证的对象资源

- `war3map.doo` 有现存内容，但项目内没有经验证的 doodad/destructable 记录解析流程；本阶段不列其对象数量、rawcode、坐标或摆放属性为已知事实。
- `maps/table/unit.ini` 的自定义单位 `u00K` 是现有定义，不足以证明其适合作为商店、任务 NPC、怪物、Boss 或场景装饰。本方案不将它指定给任何场景元素。
- 当前没有确认可用的商店建筑、树木、矿石、遗迹、祭坛或可破坏岩石 rawcode。

## 3. 必须保持未定的场景属性

以下内容未从项目数据或验证过的工具中确认，不能推断：

- 树木、岩石、遗迹、祭坛、桥梁、商店和 NPC 的对象 rawcode。
- 装饰物的旋转单位、缩放范围及默认值。
- 每种装饰物或 destructable 的寻路阻挡、攻击次数或死亡模型。
- 地形调色板 ID 对应的实际图像含义，以及导入贴图在 1.27b 中的兼容性。
- 河道宽度、桥梁寻路覆盖、悬崖可通行坡道与六人战斗空间。

## 4. 元素数量口径

- 实际新增的地图单位、装饰物、地形、障碍物和路径网格数据：**0**。

- 确认可复用的起点 rawcode：`sloc`；计划使用 6 个起点位置，但当前地图只存在 4 个。
