## 1. 坐标参考

- W3E 头部已验证：65×65 地形网格，偏移 `(-4096,-4096)`，文件大小与版本 11 的记录布局相符。
- `w3i.ini` 声明 52×52 可玩地形，镜头范围 X `-2816..2816`、Y `-3328..2816`。
- JASS `SetCameraBounds` 使用 X `-3328..3328`、Y `-3584..3072`，与 `w3i.ini` 镜头范围不一致。
- 下表建议点位限制在 X/Y `-2560..2560` 的保守内部范围；它们不是已验证的地图边缘或可达地形范围。
- 表中的 Facing、Scale 和 Pathing 属性如未能从当前数据确认，均明确保留 TBD，不作猜测。

## 8. 绘制前核对

1. 先统一 `w3i.ini` 与 JASS 中不一致的镜头范围，并确认坐标包络与实际地形边缘。
2. 将玩家槽位改为六个真人并统一 W3I、JASS、起点记录；不要把当前电脑槽位计作真人玩家。
3. 在 KKWE 中摆放六个出生点及城市设施，再逐一检查碰撞与可达性。
4. 绘制道路与河道、桥梁后检查四向入口能否到达战斗区。
5. 山路应保留绕行空间；任何可破坏岩石候选点均不得堵住唯一路径。
6. 只有确认 rawcode 与属性后，才将场景对象加入对象清单；路径和地形变更完成后再进行实际游戏验证。
