## 1. 已核实的坐标基准与地图数据

- `maps/map/war3map.w3e` 头部为 `W3E!`，版本 11，地形网格为 65×65，偏移为 `(-4096,-4096)`。
- 已确认的网格点坐标公式为 `X = -4096 + 128 × i`、`Y = -4096 + 128 × j`，其中 `i,j = 0..64`。该式描述网格点坐标；不能单独确定编辑器的绘制边界、地形单元覆盖方式或可通行性。
- 本文 X、Y 均使用地图世界坐标单位，W3E 网格点间距为 128 个世界坐标单位；这里不将其换算为现实长度。矩形 `X[a,b]、Y[c,d]` 表示包括边界的规划范围，尺寸为 `b-a` × `d-c`；面积重叠、共边和角点接触分别判断。边界或网格索引不代表 KKWE 笔刷的实际覆盖范围。
- `maps/table/w3i.ini` 声明地形尺寸 52×52，镜头范围为 X `-2816..2816`、Y `-3328..2816`；`maps/map/war3map.j` 的 `SetCameraBounds` 使用 X `-3328..3328`、Y `-3584..3072`。两者不一致，均不能替代 KKWE 实测的可绘制边界。
- `war3mapUnits.doo` 只读解析结果为 W3do 版本 8、子版本 11、4 个 `sloc`；朝向数值为 `4.712389...`，单位语义仍为 unknown。
- `maps/map/war3map.doo` 为 1,274 字节；未找到经验证的项目内空间记录解析流程。`maps/map/war3map.wpm` 为 65,552 字节；未找到经验证的路径图解析器。文件大小不用于推断对象、尺寸或阻挡。
- 上述事实不表示已经实测地形边缘、装饰物冲突或路径通行情况。

## 4. 几何审查与尚未验证事项

以下仅为规划矩形之间的几何计算，不代表实际施工或寻路通过：

- 四条主干道分别与广场接边 256；每条 NPC 支路分别与主干道及对应服务区接边 256。一转道路与南路、一转大厅各接边 256。
- 北路与二转纵段面积重叠 `256×128`，纵段覆盖北路北端完整 256 宽度；纵段与东向段共边 256，东向段与二转大厅共边 256。二转东向段与技能服务区最小矩形间距为 256。

- 六个出生框彼此无正面积重叠；P2/P3 和 P5/P6 完整共边 256，P1/P2、P1/P6、P3/P4、P4/P5 部分共边 128。北路与 P1、南路与 P4 共边 256；东路与 P2/P3、西路与 P5/P6 各共边 128。共边不能证明安全缓冲。
